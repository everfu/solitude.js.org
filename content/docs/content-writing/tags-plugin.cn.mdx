`hexo-solitude-tag` 与主题分开维护，请在 Hexo 博客根目录安装：

<PmInstall name="hexo-solitude-tag" />

该插件当前公开文档明确提供 YouTube 标签：

```markdown
{% youtube video_id [type] [cookie] %}
```

安装后重启 Hexo。使用其他语法前请先在[插件仓库](https://github.com/everfu/hexo-solitude-tag)核对；具有主题外观的短代码并不会由 Solitude 主题自动提供。
