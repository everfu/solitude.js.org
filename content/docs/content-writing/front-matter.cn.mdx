Front Matter 是 Markdown 源文件开头的 YAML 区块。通用元数据由 Hexo 处理，Solitude 会读取额外的展示字段。

```yaml
---
title: Hello Solitude
date: 2026-01-01 10:00:00
updated: 2026-01-02 12:00:00
description: Solitude 4 升级记录。
tags: [Hexo, Solitude]
categories: [博客]
cover: /img/covers/hello.jpg
locate: 上海
comment: true
toc: true
aside: true
katex: false
color: "#425AEF"
---
```

## Solitude 使用的字段

- `cover` 用于文章卡片和头图；未设置时使用 `post.default.cover`。
- `description` 会作为文章摘要，也可用于页面元数据。
- `locate` 覆盖 `post.default.locate`。
- 已配置评论服务时，`comment: false` 仍可关闭当前页面评论。
- `toc` 与 `aside` 覆盖当前文档的主题默认值。
- 全局未按页加载时，`katex: true` 会为当前页面加载 KaTeX。
- 支持的封面取色模式可使用 `color` 提供固定颜色。
- 启用 `post.ai` 后，`ai_text` 提供本地文章摘要文本。

特色页面还会使用 `type`、`data`、`banner` 和页面专属字段，具体见对应指南。评论开关键名是 `comment`，不是 `comments`。
