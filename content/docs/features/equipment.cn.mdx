## 用途

展示你常用的设备、软件、桌面或工具。

## 创建页面

在 `source/kit/index.md` 下创建页面，并设置清晰标题。

```md
---
title: 我的装备
date: 2026-01-01
type: kit
---
```

## 创建数据文件

把可重复内容放进 `source/_data/kit.yml`。

```yaml
items:
  - name: 示例项目
    description: 替换为你的实际内容。
    link: https://example.com
```

## 主题配置

如果该页面需要开关，在主题配置中启用对应模块。

```yaml
pages:
  kit:
    enable: true
    data: kit.yml
```

## 字段参考

- `name`：展示名称。
- `description`：简短说明文字。
- `link`：可选的外部或内部链接。
- `cover`：页面布局支持时使用的封面图片路径。
- `tags`：用于分组或筛选的可选标签。

建议先写一两个项目，确认页面能正常渲染，再继续扩展数据文件。
</Callout>
