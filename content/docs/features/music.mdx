---
title: "Music Page"
description: "Create the built-in Meting-based music page."
---
Create `source/music/index.md`:

```yaml
---
title: Music
date: 2026-01-01
type: music
comment: false
aside: false
---
```

Configure the player in `_config.solitude.yml`:

```yaml
meting_api: https://meting.qjqq.cn/?server=:server&type=:type&id=:id&auth=:auth&r=:r
music:
  enable: true
  id: 5144842535
  server: netease
  type: playlist
  volume: 0.8
  mutex: true
  order: list # list / random
```

The built-in page does not read a music data file. The configured Meting API and music provider must be reachable from the visitor's network.
