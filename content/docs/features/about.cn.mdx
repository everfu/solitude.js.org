---
title: "关于页"
description: "使用 source/_data/about.yml 构建主题内建关于页。"
---
创建 `source/about/index.md`：

```yaml
---
title: 关于
type: about
comment: false
aside: false
---
```

模板会直接读取 `source/_data/about.yml`。一个可用的最小数据文件如下：

```yaml
title: 关于我
authorinfo:
  leftTags: [开发者, 写作者]
  rightTags: [开源, 摄影]
  image: /img/avatar.png
contentinfo:
  sup: 你好，我是
  name: 你的名字
  title: 欢迎来到我的站点
  tip: 关于本站
  slogan: 为 Web 创造有价值的内容
  mask:
    - 认真
    - 开放
    - 持续
motto:
  title: 座右铭
  prefix: 保持
  content: 学习。
```

可选顶层区块包括 `skills`、`careers`、`personalities`、`game`、`likes`、`expertise`、`tenyear`、`award` 和 `rewardList`。建议逐个添加，并严格使用 v4 模板实际读取的字段。
