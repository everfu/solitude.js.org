---
title: "Bangumi (Third Party)"
description: "Add an anime list with the third-party hexo-bilibili-bangumi plugin."
---
<Callout type="warning">
Bangumi is not a built-in Solitude page type. The page and data are generated by a third-party plugin; compatibility and data-source behavior belong to that plugin.
</Callout>

<PmInstall name="hexo-bilibili-bangumi" />

Add configuration to Hexo `_config.yml`, not `_config.solitude.yml`:

```yaml
bangumi:
  enable: true
  source: bili
  path: bangumis/index.html
  vmid: your-user-id
  title: Anime List
  quote: Always watching
  theme: auto
  show: 1
  lazyload: true
  webp: true
  progress: true
```

Update data before generation:

```bash
hexo bangumi -u
hexo clean && hexo generate
```

See the [plugin repository](https://github.com/HCLonely/hexo-bilibili-bangumi) for supported sources, authentication, cinema/game pages, and provider-specific options. Test its generated page after every Solitude or plugin upgrade.
