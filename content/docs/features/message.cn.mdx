---
title: "留言板"
description: "使用评论服务和弹幕创建主题内建留言页。"
---
留言页复用已配置的评论服务。先完成一个评论服务配置，再创建 `source/message/index.md`：

```yaml
---
title: 留言板
type: message
comment: true
aside: false
---
```

```yaml
envelope:
  enable: true
  line: 10
  speed: 20
  hover: true
  loop: true
  page: /message/
```

留言页没有 `message.yml` 数据源，内容来自启用的 Twikoo、Waline、Valine 或 Artalk。请确认 `envelope.page` 与实际生成的页面 URL 一致。
