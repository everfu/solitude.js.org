## 用途

创建供访客留言和轻互动使用的留言板页面。

## 创建页面

在 `source/message/index.md` 下创建页面，并设置清晰标题。

```md
---
title: 留言板
date: 2026-01-01
type: message
---
```

## 创建数据文件

把可重复内容放进 `source/_data/message.yml`。

```yaml
items:
  - name: 示例项目
    description: 替换为你的实际内容。
    link: https://example.com
```

## 主题配置

如果该页面需要开关，在主题配置中启用对应模块。

```yaml
pages:
  message:
    enable: true
    data: message.yml
```

## 字段参考

- `name`：展示名称。
- `description`：简短说明文字。
- `link`：可选的外部或内部链接。
- `cover`：页面布局支持时使用的封面图片路径。
- `tags`：用于分组或筛选的可选标签。

</Callout>
