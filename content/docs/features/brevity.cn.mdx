---
title: "即刻短文"
description: "创建主题内建的短文时间线及其数据源。"
---
创建 `source/essay/index.md`：

```yaml
---
title: 即刻短文
type: brevity
banner: true
desc: 日常生活中的简短记录
cover: /img/essay-cover.jpg
comment: true
aside: false
---
```

将 `source/_data/brevity.yml` 创建为数组：

```yaml
- date: 2026-01-01 12:00:00
  content: Solitude 4 已上线。
  location: 上海
  image:
    - url: /img/moments/release.jpg
      alt: 发布页面
  link: /posts/solitude-4/
- date: 2026-01-02 18:30:00
  content: 正在收听
  aplayer:
    server: netease
    id: 123456
```

```yaml
brevity:
  enable: true
  home_mini: true
  music: true
  page: /essay/
  style: 1
  strip: 30
```

图片既可以直接写字符串，也可以使用包含 `url` 和 `alt` 的对象；视频支持 `video.player` 或 `video.bilibili`。
