---
title: "追番页面（第三方）"
description: "通过第三方 hexo-bilibili-bangumi 插件添加追番列表。"
---
<Callout type="warning">
追番不是 Solitude 内建页面类型。页面与数据由第三方插件生成，其兼容性和数据源行为由插件维护。
</Callout>

<PmInstall name="hexo-bilibili-bangumi" />

将配置写入 Hexo `_config.yml`，而不是 `_config.solitude.yml`：

```yaml
bangumi:
  enable: true
  source: bili
  path: bangumis/index.html
  vmid: your-user-id
  title: 追番列表
  quote: 生命不息，追番不止
  theme: auto
  show: 1
  lazyload: true
  webp: true
  progress: true
```

生成站点前更新数据：

```bash
hexo bangumi -u
hexo clean && hexo generate
```

支持的数据源、认证、追剧/游戏页面和服务专属选项请查看[插件仓库](https://github.com/HCLonely/hexo-bilibili-bangumi)。每次升级 Solitude 或插件后都应重新测试生成页面。
