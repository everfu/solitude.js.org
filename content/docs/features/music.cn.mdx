---
title: "音乐馆"
description: "创建主题内建的 Meting 音乐页面。"
---
创建 `source/music/index.md`：

```yaml
---
title: 音乐馆
date: 2026-01-01
type: music
comment: false
aside: false
---
```

在 `_config.solitude.yml` 中配置播放器：

```yaml
meting_api: https://meting.qjqq.cn/?server=:server&type=:type&id=:id&auth=:auth&r=:r
music:
  enable: true
  id: 5144842535
  server: netease
  type: playlist
  volume: 0.8
  mutex: true
  order: list # list / random
```

主题内建音乐页不会读取音乐数据文件。配置的 Meting API 和音乐服务必须能从访客网络访问。
