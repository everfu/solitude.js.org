## 环境

使用 Node.js **22.12.0+**，pnpm 版本以项目 `package.json` 的 `packageManager` 为准。当前模板使用 `pnpm@11.24.0`。

## 获取模板

点击 [Use this template](https://github.com/everfu/astro-solitude/generate) 创建自己的仓库，再克隆副本。替换 `YOUR_NAME` 和 `my-blog`：

```sh
git clone https://github.com/YOUR_NAME/my-blog.git
cd my-blog
pnpm install --frozen-lockfile
pnpm dev
```

打开终端提示的地址。创建模板仓库只会复制源码，不会自动发布网站。

依赖版本以项目锁文件为准，不要单独升级 Astro 或 MDX 后直接发布。
