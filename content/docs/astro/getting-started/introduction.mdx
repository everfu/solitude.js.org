## Start here

1. Create your own template repository and install dependencies.
2. Edit `src/site.config.ts` and replace the sample identity and content.
3. Write in `src/content/posts/`, build, and publish `dist/`.

## File locations

| Content | Location |
| --- | --- |
| Site and theme configuration | `src/site.config.ts` |
| Posts / custom pages | `src/content/posts/` / `src/content/pages/` |
| About, friends, equipment, updates | `src/data/` |
| Images and media | `public/` |
| Custom styles | `src/styles/custom.css` |

Use the theme as a complete project. It is not an npm theme package for an existing Astro application.
