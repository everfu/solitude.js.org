## Requirements

Use Node.js **22.12.0+** and the pnpm version in the project's `packageManager` field. The current template uses `pnpm@11.24.0`.

## Get the template

Select [Use this template](https://github.com/everfu/astro-solitude/generate), create your repository, then clone your copy. Replace `YOUR_NAME` and `my-blog`:

```sh
git clone https://github.com/YOUR_NAME/my-blog.git
cd my-blog
pnpm install --frozen-lockfile
pnpm dev
```

Open the address shown in the terminal. Creating a template copy does not publish a website.

Use the locked dependency versions. Validate changes before publishing an Astro or MDX upgrade.
