Astro Solitude 是可直接使用的博客模板，包含文章、分类、标签、特色页面、搜索与评论集成。

## 从哪里开始

1. 创建自己的模板仓库并安装依赖。
2. 编辑 `src/site.config.ts`，替换站点信息和示例内容。
3. 在 `src/content/posts/` 写作，构建后发布 `dist/`。

## 文件位置

| 内容 | 位置 |
| --- | --- |
| 站点与主题配置 | `src/site.config.ts` |
| 文章 / 自定义页面 | `src/content/posts/` / `src/content/pages/` |
| 关于、友链、装备、短文数据 | `src/data/` |
| 图片与媒体 | `public/` |
| 自定义样式 | `src/styles/custom.css` |

主题作为完整项目使用，不是通过 npm 安装到已有 Astro 项目的主题包。
