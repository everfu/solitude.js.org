先部署 Waline，服务端允许博客域名。

## 主题配置

```ts
// src/site.config.ts
import { defineSolitudeConfig } from './lib/config';

export default defineSolitudeConfig({
  theme: {
    comment: { use: 'waline', lazyload: true },
    waline: { serverURL: 'https://comments.example.com' },
  },
});
```

文章 `comment` 默认为 true；设为 false 可关闭单篇评论。关于、音乐和归档等特殊布局会省略评论框。

验证主题切换、页面直达和反复切页。完整部署说明见 [Waline 官方文档](https://waline.js.org/)。
