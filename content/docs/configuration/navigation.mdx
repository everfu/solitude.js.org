## Navigation bar

```yaml
nav:
  group:
    Project:
      Solitude: https://github.com/everfu/hexo-theme-solitude || /img/pwa/favicon.png
  menu:
    Home: /
    Posts:
      Archives: /archives/ || fas fa-folder-closed
      Categories: /categories/ || fas fa-clone
      Tags: /tags/ || fas fa-tags
  right:
    random: true
    custom:
      - name: About
        url: /about/
        icon: fas fa-user
        id: about-button
```

The value before `||` is a URL and the value after it is an icon. Nested menu objects create dropdown groups.

## Context menu

```yaml
right_menu:
  enable: true
  ctrlOriginalMenu: true
  custom_list:
    - name: Random post
      click: Solitude.randomPost()
      id: menu-random-post
      icon: fas fa-tower-broadcast
```

Use the [Browser API](/docs/configuration/browser-api) for custom actions. Legacy global calls are not supported extension contracts in 4.0.
