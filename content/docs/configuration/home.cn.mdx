```yaml
hometop:
  enable: true
  banner:
    title: 分享技术<br />与日常生活
    desc:
      - 开发者的笔记
      - 项目与实验
    icon:
      JavaScript:
        img: /img/icons/javascript.png
        color: "#f7cb4f"
  group:
    热门: /tags/热门/ || fas fa-fire || linear-gradient(to right,#f65,#ffbf37)
  recommendList:
    enable: true
    sup: 推荐
    title: 从这里开始
    url: /about/
    img: /img/default.avif
    color: none

index_post_list:
  direction: column # row / column
  column: 2
  cover: both
```

启用即刻短文后，可通过 `brevity.home_mini: true` 在首页加入精简动态。推荐位文案应保持简短，并检查明暗模式下的对比度。
