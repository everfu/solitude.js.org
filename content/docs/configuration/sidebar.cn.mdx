## 用途

侧边栏服务于阅读。它可以展示作者身份、文章目录、热门标签和站点信息，但每多一个模块都会分走正文注意力。

## 示例

```yaml
aside:
  enable: true
  card:
    enable: true
    name: 你的名字
    description: 记录 Web、设计与生活
  toc:
    enable: true
  tags:
    enable: true
  siteinfo:
    enable: true
```

## 实用默认值

- 长文章建议保留文章目录。
- 如果站点以个人作者为中心，可以启用个人卡片。
- 统计类模块在数据不足时可以先关闭。
- 增加多个侧边栏模块后，要检查移动端布局。
