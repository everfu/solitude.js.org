---
title: "站点配置"
description: "配置 Hexo 站点身份与 Solitude 站点标记。"
icon: "Globe"
---
规范站点元信息由 Hexo 管理，Solitude 只管理主题中显示的站点标记。

```yaml
# _config.yml
title: 我的博客
subtitle: 笔记与项目
author: 你的名字
language: zh-CN
url: https://example.com

# _config.solitude.yml
site:
  name:
    class: text # text / i_class / img
    custom: 我的博客
  icon: /img/pwa/favicon.png
```

`i_class` 对应图标类名，`img` 对应图片路径。确认图标和图片名称能在生成站点中访问；不要在 `site` 下重复填写 Hexo 的 `title`、`author` 或 `url`。
