## Solitude 是什么

Solitude 是一个面向个人博客的 Hexo 主题，强调安静的阅读体验、清晰的信息层级，以及可按需开启的功能模块。它负责博客的外观、文章展示、页面组件、导航体验和第三方服务接入，而不是一个独立的网站生成器。

## 主题提供什么

- 首页顶部、推荐内容、分类入口、公告和其他展示模块。
- 文章页目录、版权信息、上一篇下一篇、标签、分类和阅读相关信息。
- 侧边栏个人卡片、站点统计、标签、目录和自定义组件。
- 关于、友情链接、画廊、音乐馆、追番、装备、留言板等特色页面。
- 本地搜索、Algolia、DocSearch，以及 Twikoo、Waline、Artalk、Giscus、Valine 等评论系统。

## 配置入口

Solitude 的主题配置集中在 `_config.solitude.yml`。Hexo 根目录中的 `_config.yml` 仍然负责站点标题、链接、语言、主题名称等 Hexo 基础行为；主题模块、外观、页面、评论和搜索则交给 Solitude 配置。

```text
博客目录
  _config.yml
  _config.solitude.yml
  source
  themes
    solitude
```

## 如何继续

如果还没有安装主题，先阅读安装与首次运行；如果已经可以启动博客，可以直接进入配置章节，按首页、导航、侧边栏、文章页、外观、SEO 等区域调整主题。特色页面和第三方集成可以在需要时再开启。
