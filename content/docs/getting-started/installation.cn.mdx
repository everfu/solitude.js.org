---
title: "安装"
description: "安装 Solitude 4，并准备博客根目录中的主题配置。"
---
## 创建或进入 Hexo 博客

```bash
npm install -g hexo-cli
hexo init my-blog
cd my-blog
npm install
```

## 安装 Solitude 4

<Tabs items={["npm", "Git"]}>
<Tab>

```bash
npm install hexo-theme-solitude@4
```

</Tab>
<Tab>

```bash
git clone --branch v4.0.0 --depth 1 https://github.com/everfu/hexo-theme-solitude.git themes/solitude
```

</Tab>
</Tabs>

在 Hexo 根配置中启用主题：

```yaml
# _config.yml
theme: solitude
```

## 安装渲染器

```bash
npm install hexo-renderer-pug hexo-renderer-stylus
```

它们负责编译主题模板和样式。通过 npm 安装主题时会自动安装，Git 方式安装则需要手动执行此步骤。

## 复制主题配置

<Tabs items={["npm", "Git"]}>
<Tab>

```bash
cp node_modules/hexo-theme-solitude/_config.yml _config.solitude.yml
```

</Tab>
<Tab>

```bash
cp themes/solitude/_config.yml _config.solitude.yml
```

</Tab>
</Tabs>

后续只修改博客根目录中的副本，不要修改 `node_modules` 内的文件。已有用户应合并新配置，而不是覆盖定制内容；参阅[升级到 4.0](/cn/docs/getting-started/upgrade-v4)。
