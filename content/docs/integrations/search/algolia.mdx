---
title: "Algolia Search"
description: "Connect the Solitude 4 search UI to a Hexo Algolia index."
---
Create an Algolia application and populate its index using a Hexo Algolia plugin. The index credentials belong in Hexo `_config.yml`:

```yaml
algolia:
  appId: your-app-id
  apiKey: your-search-only-key
  indexName: your-index-name
```

Enable the theme UI in `_config.solitude.yml`:

```yaml
search:
  enable: true
  type: algolia
  tags: [Solitude, Hexo]
  algolia:
    hits:
      per_page: 6
```

Use a search-only key in generated pages, never an Admin API key. Upload the index, open the search dialog, and verify pagination plus PJAX navigation from a result.
