---
title: "DocSearch 搜索"
description: "在 Solitude 4 中配置现有 Algolia DocSearch 索引。"
---
DocSearch 需要已获批准或自托管的爬虫，并且索引已经存在。`_config.solitude.yml` 中只填写公开搜索凭据：

```yaml
search:
  enable: true
  type: docsearch
  docsearch:
    appId: your-app-id
    apiKey: your-search-only-key
    indexName: your-index-name
    option:
      insights: true
```

Solitude 会把 `option` 传给 DocSearch 客户端。爬虫凭据不能进入生成站点；部署后检查 DocSearch 样式、脚本、弹窗和结果链接。
