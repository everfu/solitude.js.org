---
title: "Posts"
description: "Configure post defaults, metadata, sharing, expiration, and related posts."
icon: "FileText"
---
```yaml
post:
  default:
    cover:
      - /img/default.avif
    locate: China
    copyright:
      enable: true
      author: /img/avatar.png
      license: CC BY-NC-SA 4.0
      licenurl: https://creativecommons.org/licenses/by-nc-sa/4.0/
  ai:
    enable: false
    modelName: Local AI
  meta:
    date: true
    updated: true
    locate: false
    wordcount: true
    readtime: true
    pv: false
    comment: false
  share:
    enable: true
    list: [link, qrcode]
  covercolor:
    enable: false
    mode: local # local / api / ave
    api: https://example.com/color?img=
    time: 43200000

expire:
  enable: true
  time: 180
  position: top

related_post:
  enable: true
  limit: 4
  date_type: created

copy:
  enable: true
  copyright:
    enable: true
    limit: 50
```

`wordcount` and `readtime` require `hexo-wordcount`. Individual posts can override defaults with Front Matter such as `cover`, `locate`, `comment`, `toc`, `aside`, and `copyright`.
