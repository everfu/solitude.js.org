## 规范元数据

```yaml
# _config.yml
title: 我的博客
subtitle: 笔记与项目
description: 你的名字发布的文章
author: 你的名字
url: https://example.com
```

`url` 应使用最终生产域名。文章标题、描述、日期、封面、标签和分类来自 Front Matter。

## Open Graph 与站点验证

```yaml
# _config.solitude.yml
OpenGraph:
  enable: true
  options:
    twitter_card: summary_large_image
    twitter_site: "@example"

verify_site:
  - name: google-site-verification
    content: verification-token
  - name: baidu-site-verification
    content: verification-token
```

Solitude 不负责生成 `robots.txt` 或 `sitemap.xml`。请安装相应 Hexo 生成器插件，并确保它们使用同一个生产环境 `url`。
