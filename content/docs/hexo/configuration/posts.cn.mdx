---
title: "文章配置"
description: "配置文章默认值、元信息、分享、过期提醒和相关文章。"
icon: "FileText"
---
```yaml
post:
  default:
    cover:
      - /img/default.avif
    locate: China
    copyright:
      enable: true
      author: /img/avatar.png
      license: CC BY-NC-SA 4.0
      licenurl: https://creativecommons.org/licenses/by-nc-sa/4.0/
  ai:
    enable: false
    modelName: 本地 AI
  meta:
    date: true
    updated: true
    locate: false
    wordcount: true
    readtime: true
    pv: false
    comment: false
  share:
    enable: true
    list: [link, qrcode]
  covercolor:
    enable: false
    mode: local # local / api / ave
    api: https://example.com/color?img=
    time: 43200000

expire:
  enable: true
  time: 180
  position: top

related_post:
  enable: true
  limit: 4
  date_type: created

copy:
  enable: true
  copyright:
    enable: true
    limit: 50
```

`wordcount` 和 `readtime` 依赖 `hexo-wordcount`。单篇文章可以通过 `cover`、`locate`、`comment`、`toc`、`aside`、`copyright` 等 Front Matter 字段覆盖默认值。
