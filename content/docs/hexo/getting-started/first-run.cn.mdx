---
## 启动本地服务

```bash
hexo clean
hexo generate
hexo server
```

打开 Hexo 输出的地址，通常是 `http://localhost:4000`。

## 检查结果

- 首页已使用 Solitude，静态资源没有 404。
- 浏览器控制台没有 ES 模块、配置 JSON 或动态导入错误。
- `_config.yml` 包含 `theme: solitude`，且根目录存在 `_config.solitude.yml`。
- 未启用的搜索、评论、音乐等模块不会被无条件请求。

基础站点正常后，建议依次配置站点身份、导航、首页、侧边栏和文章；搜索与评论应在对应外部服务准备好之后再启用。
