## Solitude 4 是什么

Solitude 4 是面向个人博客的 Hexo 主题，提供首页模块、文章元信息、侧边栏、特色页面、搜索、评论、PWA 和浏览器 API。

4.0 使用原生 ES 模块重构了浏览器运行时。搜索、音乐、友链、右键菜单、翻译、文章 AI 和封面取色会按配置动态加载；统一的 PJAX 生命周期会在页面切换时清理监听器和第三方实例。

## 运行要求

- Hexo 7.0.0 或更高版本。
- Node.js 14.0.0 或更高版本。
- 较新的 Chrome、Edge、Firefox 或 Safari；不支持 Internet Explorer。

## 配置文件

博客根目录的 `_config.yml` 负责 Hexo 的标题、作者、URL、语言和主题选择；`_config.solitude.yml` 负责 Solitude 的模块与外观。

```text
my-blog/
  _config.yml
  _config.solitude.yml
  source/
  themes/solitude/   # 仅 Git 安装方式
```

<Callout type="info">
本文档示例以 Solitude v4.0.0 为准。从 3.x 迁移时，请按照[升级到 4.0](/cn/docs/hexo/getting-started/upgrade-v4)的步骤，将自己的配置值合并到全新的 Solitude 4 配置中。
</Callout>
