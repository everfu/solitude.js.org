Solitude 4 是 Hexo 博客主题，提供文章、首页模块、特色页面、搜索和评论集成。

## 环境

- Hexo **7+**，Node.js **18+**（以主题 `package.json` 为准）。
- 若使用 `hexo-solitude-tag@2`，需要 Hexo **8** 和 Node.js **20.19+**。

## 文件位置

| 内容 | 位置 |
| --- | --- |
| Hexo 地址、语言、作者 | `_config.yml` |
| 主题配置 | `_config.solitude.yml` |
| 文章与页面 | `source/` |
| 数据文件 | `source/_data/` |

从安装开始。3.x 用户按升级指南合并配置，保留自己的值。
