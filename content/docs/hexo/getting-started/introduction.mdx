Solitude 4 is a Hexo blog theme with posts, homepage modules, pages, search, and comment integrations.

## Requirements

- Hexo **7+**, Node.js **18+**, as declared in the theme `package.json`.
- `hexo-solitude-tag@2` requires Hexo **8** and Node.js **20.19+**.

## File locations

| Content | Location |
| --- | --- |
| Hexo URL, language, author | `_config.yml` |
| Theme configuration | `_config.solitude.yml` |
| Posts and pages | `source/` |
| Datasets | `source/_data/` |

Start with installation. If upgrading from 3.x, merge configuration using the upgrade guide and preserve your own values.
