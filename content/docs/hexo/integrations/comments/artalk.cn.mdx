---
title: "Artalk 评论"
description: "将 Artalk 配置为 Solitude 4 顶层评论服务。"
---
在 `_config.solitude.yml` 中配置公共行为并选择服务：

```yaml
comment:
  use: artalk
  commentBarrage: false
  lazyload: true
  count: true
  sidebar: false
  pv: false
  avatar: https://gravatar.com/avatar

artalk:
  server: https://your-artalk.example.com
  site: My Blog
  option:
```

服务配置是顶层区块，不是 `comment` 的子项。site 必须与 Artalk 后台创建的站点名称一致。

页面 Front Matter 可使用 `comment: false` 单独关闭评论。请验证首次加载、反复 PJAX 导航、发表评论、明暗模式、支持时的计数显示，以及生产域名白名单。
