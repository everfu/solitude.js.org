---
title: "Valine 评论"
description: "将 Valine 配置为 Solitude 4 顶层评论服务。"
---
在 `_config.solitude.yml` 中配置公共行为并选择服务：

```yaml
comment:
  use: valine
  commentBarrage: false
  lazyload: true
  count: true
  sidebar: false
  pv: false
  avatar: https://gravatar.com/avatar

valine:
  appId: your-leancloud-app-id
  appKey: your-leancloud-app-key
  serverURLs:
  avatar: monsterid
  visitor: false
  style: true
  option:
```

服务配置是顶层区块，不是 `comment` 的子项。在 LeanCloud 中限制生产域名，任何情况下都不要暴露 Master Key。

页面 Front Matter 可使用 `comment: false` 单独关闭评论。请验证首次加载、反复 PJAX 导航、发表评论、明暗模式、支持时的计数显示，以及生产域名白名单。
