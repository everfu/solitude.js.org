---
title: "本地搜索"
description: "生成本地 XML 索引并启用 Solitude 4 搜索模块。"
---
在 Hexo 博客中安装 XML 搜索索引生成器：

<PmInstall name="hexo-generator-search" />

配置 Hexo `_config.yml`：

```yaml
search:
  path: search.xml
  field: post
  content: true
```

配置 `_config.solitude.yml`：

```yaml
search:
  enable: true
  type: local
  tags: [Solitude, Hexo]
  ai:
    enable: true
    url: https://example.com/ai-search
  local:
    preload: false
    CDN: /search.xml
```

`search.ai.url` 是本地搜索中显示的外部链接，不是 AI 请求接口。生成后检查 `/search.xml`，并分别按标题、标签和正文进行搜索。
