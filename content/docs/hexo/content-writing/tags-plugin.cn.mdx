标签插件单独安装，v2 需要 Hexo **8** 和 Node.js **20.19+**；Hexo 7 用户使用 `hexo-solitude-tag@1`。

```sh
npm install hexo-solitude-tag@2
```

## 标签来源

插件提供 `note`、`subnote`、隐藏内容、按钮、行内图片、标签、时间线、友链、乐谱、系列和 Chart.js。主题提供 Gallery、Mermaid 与 Tabs。

```md
{% hideInline Secret text,Click to reveal %}

{% btn https://example.com,Visit,fas fa-link,blue outline %}

{% youtube video_id [type] [cookie] %}
```

重启 Hexo 后重新生成。完整参数和迁移示例见[插件仓库](https://github.com/everfu/hexo-solitude-tag)。Hugo Shortcodes 和 Astro MDX 不适用于 Hexo。
