---

The tag plugin is installed separately. V2 requires Hexo **8** and Node.js **20.19+**; Hexo 7 users should use `hexo-solitude-tag@1`.

```sh
npm install hexo-solitude-tag@2
```

## Tag providers

The plugin provides notes, hidden content, buttons, inline images, labels, timelines, friend links, scores, series, and Chart.js. The theme provides Gallery, Mermaid, and Tabs.

```md
{% hideInline Secret text,Click to reveal %}

{% btn https://example.com,Visit,fas fa-link,blue outline %}

{% youtube video_id [type] [cookie] %}
```

Restart Hexo and regenerate. See the [plugin repository](https://github.com/everfu/hexo-solitude-tag) for full parameters and migration examples. Hugo shortcodes and Astro MDX do not work in Hexo.
