---
title: "我的装备"
description: "创建主题内建装备页及其分组数据。"
---
创建 `source/kit/index.md`，并让 `data` 指向 `source/_data` 下不带扩展名的数据文件：

```yaml
---
title: 我的装备
type: kit
data: equipment
banner: true
desc: 每天使用的工具
cover: /img/kit-cover.jpg
comment: true
aside: false
---
```

```yaml
# source/_data/equipment.yml
- class_name: 电脑
  description: 开发设备
  equipment_list:
    - name: 笔记本电脑
      image: /img/equipment/laptop.jpg
      specification: 16 GB / 1 TB
      description: 主力开发设备
      link: /posts/my-setup/
```

外部 `link` 会在新标签页打开，站内链接保留在当前站点。配置评论服务后，每个装备项会显示快捷回复入口。
