---
title: "最近评论"
description: "从已启用评论服务创建主题内建最近评论页。"
---
创建 `source/recentcomments/index.md`。页面类型使用单数：

```yaml
---
title: 最近评论
type: recentcomment
banner: true
desc: 最新讨论
cover: /img/comments-cover.jpg
comment: false
aside: false
---
```

```yaml
recent_comments:
  enable: true
  limit: 50
  cache: 0.2
  page: /recentcomments/
```

数据来自 `comment.use` 中的第一个评论服务。主题模板支持 Twikoo、Waline、Valine 和 Artalk；Giscus 不提供该最近评论视图。
