description: "通过第三方 hexo-gallery 标签插件嵌入瀑布流相册。"
---
<Callout type="warning">
Solitude 4 没有内建的 `gallery` 页面类型。本指南使用第三方块标签，并将其放在普通 Hexo 文章或页面中。
</Callout>

<PmInstall name="hexo-gallery" />

创建普通页面，并在 Markdown 正文中使用插件标签：

```markdown
---
title: 相册
date: 2026-01-01
comment: false
aside: false
---

{% gallery "title:城市漫步" "author:你的名字" "col:3" "show:6" %}
/img/gallery/01.jpg
/img/gallery/02.jpg
/img/gallery/03.jpg
{% endgallery %}
```

插件还支持 `site`、`date`、`platform`、`background`、`titlecolor` 和 `desccolor`。详细说明见[插件仓库](https://github.com/Pidbid/hexo-gallery)；其 CSS、懒加载和 PJAX 行为需要与主题分开测试。
