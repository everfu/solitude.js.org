---
title: "友情链接"
description: "配置友链数据与 v4 异步渲染。"
---
创建 `source/links/index.md`：

```yaml
---
title: 友情链接
type: links
data: links
banner: true
desc: 值得访问的站点
comment: true
aside: false
---
```

创建 `source/_data/links.yml`：

```yaml
swiper: true
banner_suffix: ""
links:
  - class_name: 朋友们
    descr: 我关注的个人站点
    type: item # item / card / discn
    suffix: ""
    link_list:
      - name: 示例站点
        link: https://example.com
        avatar: https://example.com/avatar.png
        descr: 一个示例站点
        tag: 朋友
        color: "#425AEF"
```

```yaml
page:
  links:
    async_threshold: 200
```

友链总数超过非负整数阈值时，v4 会先渲染占位内容，再异步请求 `/links.json`。只要友链数据存在，Hexo 就会自动生成该 JSON。请分别测试阈值以下的直出模式和阈值以上的异步模式。
