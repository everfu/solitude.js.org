---
title: "Friend Links"
description: "Configure friend-link data and v4 asynchronous rendering."
---
Create `source/links/index.md`:

```yaml
---
title: Friend Links
type: links
data: links
banner: true
desc: Sites worth visiting
comment: true
aside: false
---
```

Create `source/_data/links.yml`:

```yaml
swiper: true
banner_suffix: ""
links:
  - class_name: Friends
    descr: Personal sites I follow
    type: item # item / card / discn
    suffix: ""
    link_list:
      - name: Example
        link: https://example.com
        avatar: https://example.com/avatar.png
        descr: An example site
        tag: Friend
        color: "#425AEF"
```

```yaml
page:
  links:
    async_threshold: 200
```

When the total link count exceeds the non-negative integer threshold, v4 renders placeholders and fetches `/links.json` asynchronously. Hexo generates that JSON automatically whenever link data exists. Test direct rendering below the threshold and asynchronous rendering above it.
