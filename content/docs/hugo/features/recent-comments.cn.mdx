---

## 创建页面

创建 `content/recentcomments/_index.md`：

```yaml
---
title: 最新评论
type: recentcomment
---
```

启用 `recent_comments`，设置数量、缓存时间和页面地址，再创建页面。当前聚合读取 Valine API，需要配置 Valine 的客户端标识与服务地址；其他评论框服务不会启用聚合。

## 示例

```yaml
params:
  solitude:
    comment:
      use: valine
    valine:
      appId: YOUR_APP_ID
      appKey: YOUR_CLIENT_KEY
      serverURLs: https://comments.example.com
    recent_comments:
      enable: true
      limit: 50
      cache: 0.2
      page: /recentcomments/
```
