---
title: "留言页"
description: "创建由当前评论服务驱动的独立留言页。"
---

## 创建页面

创建 `content/message/_index.md`：

```yaml
---
title: 留言页
type: message
---
```

在页面设置 `comment: true`，并配置一个受支持的评论服务。信封动画由 `params.solitude.envelope` 及其 `page` 地址控制。

## 配置或数据示例

```yaml
---
title: Message Board
type: message
comment: true
---
```

最终结构请对照 `exampleSite/content` 与 `exampleSite/data` 中的对应文件。
