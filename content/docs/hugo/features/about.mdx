title: "About Page"
description: "Build the modular About page from a Hugo data file."
---

## Create the page

Create `content/about/_index.md`:

```yaml
---
title: About Page
type: about
data: about
---
```

The `sections` array controls both module selection and render order. Supported section types are defined by the theme; an unknown type fails the build instead of silently rendering an empty block.

## Configuration or data example

```yaml
title: About Solitude
sections:
  - type: intro
    greeting: Hello
    name: Solitude
    description: A Hugo theme for content-focused sites
```

Compare the final structure with the matching files in `exampleSite/content` and `exampleSite/data`.
