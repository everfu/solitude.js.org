---
title: "Recent Comments"
description: "Aggregate recent comments into a dedicated page and sidebar modules."
---

## Create the page

Create `content/recentcomments/_index.md`:

```yaml
---
title: Recent Comments
type: recentcomment
---
```

Enable `recent_comments`, set its limit, cache duration, and page URL, then create the page. Aggregation currently uses the Valine API; configure its client identifiers and service URL. Other comment widgets do not enable aggregation.

## Example

```yaml
params:
  solitude:
    comment:
      use: valine
    valine:
      appId: YOUR_APP_ID
      appKey: YOUR_CLIENT_KEY
      serverURLs: https://comments.example.com
    recent_comments:
      enable: true
      limit: 50
      cache: 0.2
      page: /recentcomments/
```
