Solitude Hugo 是原生 Hugo 博客主题，包含文章、特色页面、搜索、评论和内容 Shortcodes。

## 主题实景

![Hugo Solitude 示例首页的桌面实景](/showcase/hugo-home.webp)

首页的置顶区把封面与文章标题并排显示，读者也可以从分类栏进入文章列表。 [浏览 Hugo 示例博客](https://hugo-solitude.efu.me/)

## 环境

Hugo **0.164.0+** 和 Git。正常构建不需要 Node.js。

## 文件位置

| 内容 | 位置 |
| --- | --- |
| 标准配置与主题设置 | 站点 `hugo.yaml`，主题字段在 `params.solitude` |
| 文章 | `content/posts/` |
| 特色页面 | `content/页面名/_index.md` |
| 数据 / 静态资源 | `data/` / `static/` |
| 自定义样式 | `assets/css/custom.css` |

从安装开始。已有 Hexo 内容需转换配置、字段和标签语法。
