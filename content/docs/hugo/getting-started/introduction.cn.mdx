## Solitude Hugo 是什么

Solitude Hugo 是 Solitude 主题的 Hugo 原生实现。它使用 Go Templates、Hugo Pipes、Menus、Taxonomies 和 Page Collections，同时保留熟悉的页面结构、特色页面、侧栏和交互体验。

构建站点只需要 **Hugo 0.164.0 或更高版本**，不需要 Node.js、npm、PostCSS、Sass 或 Stylus。

## 配置放在哪里

语言、分类体系、输出格式、分页和站点元数据使用 Hugo 标准配置；Solitude 专属配置统一放在 `hugo.yaml` 的 `params.solitude` 下。

```yaml
title: 我的博客
theme: solitude

params:
  solitude:
    site:
      name:
        class: text
        custom: 我的博客
```

第一次使用请先阅读[安装](/cn/docs/hugo/getting-started/installation)，再按需要查阅配置、内容、特色页面和集成章节。已有 Hexo 站点应先阅读[从 Hexo 迁移](/cn/docs/hugo/migration/from-hexo)，不要直接复制旧配置。
