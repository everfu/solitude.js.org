Solitude Hugo is a native Hugo blog theme with posts, pages, search, comments, and content shortcodes.

## Requirements

Hugo **0.164.0+** and Git. Normal builds do not require Node.js.

## File locations

| Content | Location |
| --- | --- |
| Standard and theme configuration | Site `hugo.yaml`, with theme fields under `params.solitude` |
| Posts | `content/posts/` |
| Special pages | `content/page-name/_index.md` |
| Data / static assets | `data/` / `static/` |
| Custom styles | `assets/css/custom.css` |

Start with installation. Existing Hexo content needs configuration, field, and tag conversion.
