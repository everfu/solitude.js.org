## 模块顺序

```yaml
params:
  solitude:
    aside:
      position: 1
      home:
        noSticky: about
        Sticky: allInfo
      post:
        noSticky: about
        Sticky: newestPost,allInfo
      page:
        noSticky: about
        Sticky: newestPost,allInfo
```

内建模块包括 `about`、`newestPost` 和 `allInfo`。逗号分隔值中的顺序就是渲染顺序。

作者卡片、目录、标签云和站点信息分别位于 `aside.my_card`、`aside.toc`、`aside.tags` 与 `aside.siteinfo`。Hugo 原生提供字数和阅读时长；访问量仍需要已启用的服务提供者。
